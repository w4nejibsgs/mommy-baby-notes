# “我奶奶生了七八个娃都没事儿，现在的女人就是娇气！”事实真的是这样吗？

> 更新时间：2026-09-17 (UTC+8)

经常会听到一些男性同胞用鄙夷不屑、怒其不争的语气轻描淡写地抛出这样的言论：**“我奶奶生了七八个娃都没事儿，现在的女人就是娇气！”**

姐妹们，你们听了气不气？！气不气？！是不是气得都不知道怎么怼回去了？

小编
今天我们就来摆事实、讲道理，用正确的姿势透析这个问题。

首先，我们要搞清楚的第一个问题是：以前的女人生七八九十个娃是不是“都没事儿”。
我们会从孕产妇死亡率、新生儿死亡率、产后生活质量这3个方面来解析。
孕产妇死亡率和新生儿死亡率     降低孕产妇死亡率是联合国千年发展计划中的重要一项，自古以来，我们中国人也把女性分娩形容为“过鬼门关”。孕产妇死亡率一直是衡量一个地区或国家经济社会发展水平的重要考核指标。随着我国经济社会水平的发展和医疗保健水平的提升，孕产妇死亡率和新生儿死亡率这两项指标正在发生天翻地覆的变化。

     万恶的旧社会由于没有查到文献资料，所以没有准确数据，我们从解放初期开始观察。

**每一万个孕产妇死亡28个，每一千个婴儿死亡120个。**

据推算，全国的这个数据大致是1500/10万。也就是10万例分娩有1500位产妇死亡，一百次分娩中就有1.5位产妇死亡，也就是生一次孩子有1.5%的概率死掉。

请问，这是否能算“没事儿”！

再来看一张统计图表

     从图表中我们可以看到，1990年，在农村每10万例分娩中有110多位产妇丧生，城市情况稍好，50/10万。而到了2016年，城乡差距基本消除，数据下降到了20左右。
再来看一张孕产妇死亡率地区间差异图

     这是1996年和2015年（请大家注意，这个时间段是中国近200年以来最好的时代，医疗保障体系逐步完善）的孕产妇死亡率地区间差异图，红色到蓝色依次代表孕产妇死亡率从高到低。

**看见那些触目惊心的红色了吗？**请问，什么叫生七八九十个娃“没事儿”？！产后生活质量      再来说说产后生活质量的问题。以前的人，多产、难产，盆底肌损伤、会阴撕裂、膀胱阴道瘘.....等等，都是极有可能发生的严重并发症，这些并发症将让母亲们以后的生活质量大受影响。如常常疼痛瘙痒的会阴部疤痕、让老年女性不敢跳不敢大笑不敢打喷嚏的尿失禁和子宫脱垂等等……每一款都能让一位母亲的生活质量大大下降。

请问，这是否能算“没事儿”？！

     产后恢复是近二十年才被重视起来的问题，这也是社会经济发展、文明进步的表现。

      这里还要提的是“住院分娩”的概念，为降低孕产妇、新生儿死亡率、分娩并发症发生率，我国推行“住院分娩”政策。现在，无论城市还是农村，几乎所有产妇都会选择去医院分娩，最大限度保障母婴安全。所有以前的产妇说什么“上一秒还在田里，下一秒回家生孩子”、“今天生孩子，明天就为全家做饭”之类的实实在在是女性无可奈何之举呀！

新生儿出生体重逐年增加
